# SignalDesk — Trading Assistant AI

SignalDesk is a free, browser-based paper-trading workspace. It combines public crypto market data, transparent technical indicators, risk sizing, a virtual $10,000 portfolio, and a local trade journal.

## Highlights

- BTC, ETH, BNB and SOL market watch
- RSI, moving averages, volatility and explainable Buy Watch / Sell Watch / Wait signals
- Paper buy/sell orders—no exchange keys and no real money
- 0.5–5% risk calculator with planned-loss visibility
- Persistent portfolio and trade journal using browser storage
- CSV export, responsive layout and installable PWA metadata
- Offline/simulated fallback if the public market feed is unavailable

## Run locally

```bash
npm run check
npm test
npm run build
npx serve dist
```

## Safety

This project is educational software, not financial advice. It does not place real orders or promise returns. Cryptocurrency trading can cause substantial losses.
